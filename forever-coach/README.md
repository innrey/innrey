# ForeverCoach

Аддон для WoW Forever и инструкции для Claude Code, чтобы Claude вёл тебя по прокачке. Аддон видит твоё состояние, Claude по нему пишет в чате, что делать дальше, и обновляет план, который аддон показывает в игре.

## Как это устроено

Аддоны WoW работают в песочнице: в интернет они не ходят, а на диск пишут только при `/reload`, выходе из игры или смене персонажа. Поэтому связь такая:

```
Игра (аддон) --/fc sync--> SavedVariables/ForeverCoach.lua --> Claude Code (/next)
Игра (аддон) <--/reload--- ForeverCoach/Plan.lua           <-- Claude Code (пишет план)
```

- **В игре, в реальном времени** (без Claude): свободные слоты и серое в сумках, КД камня возвращения и куда он привязан, КД телепорта на Лунную поляну, отдых, квесты к сдаче, свободные очки талантов, прочность. Окно аддона показывает шаги от Claude или базовый маршрут для твоего уровня и квесты, которые можно бросить. В журнале квестов — метки `[SKIP]`, `[?]`, `[!]`.
- **Claude** читает снимок (персонаж, место, здоровье и цель, баффы, квесты, экипировка и содержимое сумок, банк с последнего визита, таланты, ранги заклинаний, профессии, характеристики, репутация), пишет следующие шаги, помечает квесты и ищет свежие новости о Forever.
- **Гид со стрелкой 1–30**: готовый маршрут ночного эльфа-друида (`plan/guide.txt`, логика и деньги — `plan/route.md`). Стрелка TomTom ведёт к нужному NPC или мобам, а аддон сам переходит к следующему шагу, когда квест взят, выполнен, сдан, ты прилетел в зону, выучил заклинание или привязал камень. На шагах обучения видно, хватает ли денег. Точки аддон берёт из базы Questie. Нужны аддоны TomTom и Questie. Ушёл с маршрута — спроси Claude «куда дальше?», он поправит гид.

Аддон ничего не делает за тебя: он только читает данные игры и показывает их. Никаких ботов и чтения памяти — это бан.

## Установка аддона

1. Найди папку клиента Forever внутри папки игры (у Classic это `_classic_era_`; у Forever название посмотри у себя).
2. Подключи папку `ForeverCoach` в `Interface\AddOns`. Лучше ссылкой, а не копией: тогда план, который пишет Claude, сразу попадает в игру. В Windows (командная строка от администратора):

   ```bat
   mklink /J "C:\Program Files (x86)\World of Warcraft\<папка Forever>\Interface\AddOns\ForeverCoach" "C:\путь\к\репозиторию\forever-coach\ForeverCoach"
   ```

   Если копируешь папкой — копируй заново после каждого обновления плана.
3. Если в списке аддонов он «устарел»: включи «Загружать устаревшие» или узнай номер версии командой в игре
   `/run print((select(4, GetBuildInfo())))` и впиши его в `ForeverCoach.toc` в строку `## Interface:`.
4. Назначь клавиши: Esc → Настройки → Клавиши → AddOns → ForeverCoach (Sync, Copy, окно).

Команды в игре:

| Команда | Что делает |
|---|---|
| `/fc` | показать или скрыть окно |
| `/fc sync` | сохранить снимок и сделать `/reload` (пара секунд загрузки) |
| `/fc status` | окно с текстом снимка: Ctrl+A, Ctrl+C и вставить в чат с Claude |
| `/fc guide` | текущий шаг гида в чат и стрелка заново |
| `/fc next` | пропустить шаг гида |
| `/fc lock`, `/fc unlock` | закрепить окно или разрешить двигать |
| `/fc reset` | сбросить позицию окна |

## Claude Code на твоём компьютере

1. Установи Claude Code: https://code.claude.com/docs
2. Открой терминал в папке `forever-coach` и запусти `claude`. Он прочитает `CLAUDE.md` и поймёт, что он твой тренер.
3. При первом `/next` скажи путь к папке игры — Claude найдёт `SavedVariables/ForeverCoach.lua` и запомнит путь в `.coach-local.md`.

Команды в Claude Code:

| Команда | Что делает |
|---|---|
| `/next` | прочитать снимок и сказать, что делать дальше; обновить `Plan.lua` |
| `/next <текст из /fc status>` | то же по вставленному тексту — без `/reload` |
| `/update-plan` | найти свежие новости Forever и обновить маршрут |
| `/update-plan foreverwow` | то же, с упором на конкретный сайт |
| `/loop 3m /next` | Claude сам проверяет снимок раз в 3 минуты и отвечает, только когда ты нажал Sync |
| `/loop 2h /update-plan` | проверять новости раз в 2 часа |

Цикл в игре: **играешь → Sync → Claude пишет шаги в чате и обновляет план → в игре ещё раз Sync (или `/reload`), чтобы план появился в окне аддона.**

Без Claude Code тоже можно: `/fc status` → скопировать → вставить в любой чат с Claude.

## Тест на WoW Classic до запуска Forever

Аддон написан под API Classic Era (патч 1.15.9, интерфейс 11509), так что Classic Era, Hardcore и Anniversary подходят для проверки. План в `Plan.lua` пока под ночного эльфа-друида, но для теста годится любой персонаж: метки для твоих квестов Claude поставит по первому снимку.

1. Подключи аддон в `<папка игры>\_classic_era_\Interface\AddOns\` (или в папку клиента, на котором играешь).
2. Перед входом включи показ ошибок: `/console scriptErrors 1`.
3. `/fc test` — самопроверка. Скопируй отчёт и отправь Claude.
4. `/fc status` — снимок. Отправь Claude: он ответит советом и пропишет метки для твоих квестов в `Plan.lua`.
5. Подтяни план (`git pull`), сделай `/reload` и проверь метки в журнале квестов и в окне аддона.
6. Проверь предупреждения: набей сумки до 3 свободных слотов, используй камень (через час сообщение «готов»), выполни квест («Выполнено: ...»).

## Ограничения

- Живого подключения нет: снимок обновляется только при Sync, `/reload` или выходе из игры. Предупреждения в окне аддона при этом работают в реальном времени.
- Метки в стандартном журнале квестов рассчитаны на журнал как в Classic. Если в Forever журнал другой, метки останутся только в окне аддона и в снимке.
- Метки по названиям в `Plan.lua` — английские. На русском клиенте Claude после первого снимка переводит их на ID квестов, которые работают в любом языке.
- Маршрут выше 30 уровня — черновик: в бете туда не пускали.
